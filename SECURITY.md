# Security Policy

## Supported versions

BookmarkUp is a browser extension with a single active line. Only the **latest
released version** receives fixes. Please make sure you are on the newest release
before reporting.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report privately through GitHub:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** (GitHub Private Vulnerability Reporting).
3. Describe the issue, the affected version, and steps to reproduce.

You can expect an initial response within a few days. Once a fix is released,
the report can be disclosed publicly with credit if you'd like it.

## Scope

In scope: the extension's own code (service worker, popup, declarativeNetRequest
rule, manifest). Out of scope: vulnerabilities in the browser itself or in
websites your bookmarks point to.
