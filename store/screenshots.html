BookmarkUp - Web Store screenshots (1280 x 800)

Five artboards for the listing. To export each at exact size: open this file in Chrome, press F12, click the element-picker and select one .frame in the Elements panel (or right-click it), then choose Capture node screenshot. That saves a pixel-perfect 1280x800 PNG. Repeat for each frame. (The dark page background here is just a backdrop; it is not part of the exported images.)
